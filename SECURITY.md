# Security

These skills direct an agent with the permissions its host provides. They are
not a sandbox or an authorization mechanism. Review instructions before use and
keep the host's approval controls enabled.

Do not put credentials in skill files, change records, or issues. For sensitive
reports, use the repository's GitHub private vulnerability reporting feature if
it is enabled. Otherwise contact the maintainer through their GitHub profile to
arrange a private channel before disclosing details. Do not assume a private
reporting channel is configured merely because this file exists.
