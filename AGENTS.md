# Repository Instructions

- Keep the package small. Do not add concepts, dependencies, or a runtime without
  a concrete requirement. Preserve reliability and traceable evidence.
- Read the affected skills and their handoffs before changing lifecycle behavior.
- Keep English and Chinese entry documentation consistent.
- Run `python scripts/validate.py` and `python -m unittest discover -s tests -v`.
- Record important changes, observed checks, and limitations in the existing
  project documentation, then create a scoped Git commit.
- Never publish secrets, personal configuration, or private execution logs.
- Do not claim real-agent or cross-platform validation unless actually observed.
